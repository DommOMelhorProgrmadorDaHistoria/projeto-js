# COMMERCIAL STORE SYSTEM PROJECT (Flavio's commercial store)

The Flavio store is an business place, operating since 1984, selling the most different merchandise of Pernambuco, Brazil. The place sells everything from fishing floats to wire, carts, and electrical boxes.

This project aims to develop a safe software of products management, inventory and sales

# Features of the project (starting at 10/22/2026):

- Users can read and create products (that go to database, saving your progress)

# Features that are intended to be added (22/11/2026)

- Users can buy products
- automatic decrease of stock
- Admins features (change products, manage, delete)
- Login as user or admin

# Future constraints/ Business rules

Balance validation: Users can only buy products if balance is better than product value Stock validation: If there is not enough stock, the system will warn the user about the stock and do not discount anything from the account
